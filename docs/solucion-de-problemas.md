# Solución de Problemas

## Problemas de Acceso

### No puedo iniciar sesión

**Síntomas:** Recibo un error al intentar entrar a mi cuenta.

**Soluciones:**

1. Verifica que tu email esté correctamente escrito
2. Asegúrate de que Bloq Mayús no esté activado
3. Haz clic en **¿Olvidaste tu contraseña?** para resetearla
4. Limpia el caché del navegador: `Ctrl+Shift+Supr` (Windows) o `Cmd+Shift+Delete` (Mac)
5. Intenta en un navegador diferente

!!! warning "Si aún no funciona"
    Contacta al equipo de soporte en support@glymm.com con tu email de cuenta.

---

### Mi sesión se cierra automáticamente

**Causa:** Por razones de seguridad, Glymm cierra automáticamente sesiones inactivas.

**Soluciones:**

1. Aumenta el tiempo de sesión en Configuración → Seguridad
2. Mantén una actividad constante en la plataforma
3. Habilita "Recordarme" al iniciar sesión

---

## Problemas de Rendimiento

### La plataforma está lenta

**Posibles causas y soluciones:**

| Causa | Solución |
|-------|----------|
| Conexión lenta | Verifica tu velocidad de internet |
| Caché lleno | Limpia el caché del navegador |
| Muchas pestañas abiertas | Cierra pestañas innecesarias |
| Versión antigua del navegador | Actualiza tu navegador |
| Mucho contenido en la página | Usa filtros para reducir datos mostrados |

### Los reportes se cargan lentamente

1. Limita el rango de fechas en tu búsqueda
2. Excluye datos innecesarios usando filtros
3. Intenta exportar a Excel en lugar de ver en pantalla
4. Contacta a soporte si el problema persiste

---

## Problemas con Turnos

### No puedo crear un turno

**Verifica que:**

- [ ] El cliente existe en tu sistema
- [ ] El profesional está disponible a esa hora
- [ ] No hay conflictos de horario
- [ ] Tienes suficientes turnos en tu plan

Si todo está bien, intenta:

1. Refrescar la página (`F5`)
2. Cerrar sesión y volver a iniciar
3. Usar un navegador diferente

### Un turno no aparece en el calendario

**Causas comunes:**

- El turno está asignado a otro profesional que no está activo
- El turno está en estado "borrador"
- Los filtros están ocultando el turno

**Soluciones:**

1. Revisa los filtros activos en el calendario
2. Verifica que el profesional esté marcado como "activo"
3. Cambia el estado del turno a "confirmado"

### No puedo cancelar un turno

**Posibles razones:**

- El turno ya fue completado
- El turno ya está cancelado
- No tienes permisos para cancelar

**Solución:**

Contacta a soporte si crees que esto es un error. Tu cuenta podría tener restricciones especiales.

## Problemas con Clientes

### No puedo crear un cliente

**Verifica que:**

- [ ] El email sea válido (si lo utilizas)
- [ ] El teléfono esté en formato correcto
- [ ] No ya exista un cliente con ese email

### Un cliente no aparece en la lista

1. Verifica que no esté desactivado
2. Usa la barra de búsqueda para encontrarlo
3. Revisa si está en una lista filtrada

### ¿Cómo reactivo un cliente eliminado?

Si marcaste el cliente como "inactivo":

1. Ve a Clientes
2. Activa el filtro "Mostrar inactivos"
3. Busca el cliente
4. Haz clic en "Reactivar"

---

## Problemas de Notificaciones

### Los clientes no reciben notificaciones

**Verifica:**

1. Las notificaciones estén habilitadas en Configuración
2. El cliente tenga email o teléfono válido
3. El intervalo de tiempo sea el correcto (por defecto 24 horas antes)

### Recibo demasiadas notificaciones

Ve a Configuración → Notificaciones y ajusta las frecuencias según tus necesidades.

---

## Problemas de Sincronización

### Mi información no se sincroniza correctamente

1. Recarga la página
2. Cierra sesión y vuelve a iniciar
3. Limpia el caché
4. Usa una ventana privada/incógnita

Si el problema persiste, contacta al equipo técnico.

---

## Errores Comunes

### "Error 500: Internal Server Error"

Esto indica un problema temporal en nuestros servidores.

**Solución:**

1. Espera 5-10 minutos
2. Intenta nuevamente
3. Si persiste, contacta a soporte

### "Error de conexión"

Tu navegador no puede conectarse a Glymm.

**Soluciones:**

1. Verifica tu conexión a internet
2. Desactiva VPN o proxy temporalmente
3. Limpia el caché del navegador
4. Intenta en otro navegador o dispositivo

### "Acceso denegado"

No tienes permisos para acceder a este recurso.

**Soluciones:**

1. Verifica que estés en la cuenta correcta
2. Pide que un administrador revise tus permisos
3. Contacta a soporte
