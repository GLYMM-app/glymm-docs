# Clientes

En esta sección puedes administrar tu base de clientes: **crear**, **editar** y **buscar** información de contacto.

## Crear cliente

**Campos**
- **Nombre:** obligatorio para guardar el cliente.
- **Teléfono:** opcional; útil para contacto rápido.
- **Fecha de última visita:** puedes registrarla manualmente. También se actualiza automáticamente cuando se asignan turnos.
- **Observaciones:** notas internas (preferencias, alergias, etc.).
