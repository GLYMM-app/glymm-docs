# Gestión de Clientes

## Introducción

La gestión eficiente de clientes es fundamental para el éxito de tu negocio. En esta guía aprenderás cómo crear, editar, buscar y gestionar tu base de clientes en Glymm.

---

## Crear un Nuevo Cliente

### Pasos para crear un cliente:

1. Dirígete a la sección **Clientes** desde el menú principal
2. Haz clic en el botón **+ Nuevo Cliente**
3. Completa los siguientes campos:

#### Campos Obligatorios

- **Nombre:** El nombre completo del cliente (requerido)
- **Teléfono:** Número de contacto principal (recomendado)

#### Campos Opcionales

- **Email:** Dirección de correo electrónico
- **Apellido:** Último nombre del cliente
- **Fecha de última visita:** Se registra manualmente o se actualiza automáticamente cuando se asignan turnos
- **Observaciones:** Notas internas (preferencias, alergias, datos de interés, etc.)
- **Dirección:** Ubicación del cliente
- **Ciudad/Código Postal:** Información de localización

4. Haz clic en **Guardar**

!!! tip "Consejo de Implementación"
    Completa el máximo de información posible. Esto ayudará a personalizar mejor la experiencia del cliente y facilitar búsquedas futuras.

---

## Editar un Cliente

### Para modificar la información de un cliente:

1. Busca el cliente en la lista
2. Haz clic en el botón **Editar** (✏️ lápiz)
3. Realiza los cambios necesarios
4. Haz clic en **Guardar cambios**

!!! note "Historial de cambios"
    Glymm guarda automáticamente un registro de quién modificó qué y cuándo.

---

## Búsqueda y Filtrado

### Búsqueda Rápida

Escribe cualquier parte del nombre del cliente en la barra de búsqueda para **filtrar la lista en tiempo real**.

**Ejemplos:**
- "Juan" - busca todos los clientes con ese nombre
- "555" - busca clientes cuyo teléfono contiene esos dígitos
- "email@" - busca por dirección de email

### Filtros Avanzados

Usa los filtros para encontrar clientes por:

- Estado (activo, inactivo)
- Fecha de última visita
- Número de visitas totales
- Servicios utilizados

---

## Vista de Lista de Clientes

La vista de clientes muestra un resumen de cada cliente con:

| Información | Descripción |
|-----------|-------------|
| **Nombre** | Nombre completo del cliente |
| **Teléfono** | Número de contacto |
| **Última visita** | Fecha de la última cita/servicio |
| **Total visitas** | Cantidad de turnos completados |
| **Acciones** | Botones para editar o eliminar |

### Acciones disponibles

- **✏️ Editar:** Modifica la información del cliente
- **🗑️ Eliminar:** Marca el cliente como inactivo
- **📊 Ver historial:** Consulta todos los turnos del cliente
- **⋮ Más opciones:** Acciones adicionales

---

## Información Adicional del Cliente

### Historial de Visitas

Cada cliente tiene un historial completo que incluye:

- Fechas de todas las visitas
- Servicios utilizados
- Profesionales que lo atendieron
- Notas específicas de cada turno
- Montos pagados

Para acceder: Haz clic en **Ver historial** desde la tarjeta del cliente.

### Preferencias del Cliente

Puedes registrar preferencias importantes:

- Servicios preferidos
- Horarios preferidos
- Profesionales preferidos
- Observaciones especiales (alergias, restricciones, etc.)

---

## Gestión de Clientes Inactivos

### Desactivar un Cliente

Si un cliente ya no es activo pero deseas mantener su información:

1. Abre el perfil del cliente
2. Haz clic en **Desactivar**
3. El cliente aparecerá en la lista de "Inactivos"

### Reactivar un Cliente

Para volver a activar un cliente inactivo:

1. Activa el filtro **Mostrar inactivos**
2. Busca el cliente
3. Haz clic en **Reactivar**

### Eliminar Permanentemente

!!! danger "Atención"
    La eliminación permanente no puede deshacerse. Contacta a soporte para ejecutar esta acción.

---

## Importar Clientes

¿Tienes clientes en otro sistema? Podemos ayudarte a importarlos.

**Pasos:**

1. Prepara un archivo CSV o Excel con los datos
2. Contacta a support@glymm.com
3. Proporciona un ejemplo del formato de datos
4. Nuestro equipo procesará la importación

**Formato recomendado:**
```
Nombre,Teléfono,Email,Observaciones
Juan Pérez,555-1234,juan@email.com,Cliente VIP
María García,555-5678,maria@email.com,
```

## Mejores Prácticas

### ✅ Recomendaciones

- Mantén la información actualizada
- Completa el máximo de campos posible
- Usa las observaciones para notas importantes
- Registra preferencias y restricciones especiales
- Revisa periódicamente la información desactualizada

### ❌ Evita

- Nombres incompletos o en mayúsculas constantes
- Números telefónicos sin formato
- Duplicar clientes con ligeras variaciones de nombre
- Dejar campos vacíos sin necesidad

---

## Preguntas Frecuentes

**¿Puedo cambiar el nombre de un cliente ya creado?**
Sí, puedes editar cualquier información del cliente en cualquier momento.

**¿Qué pasa si elimino un cliente?**
Los datos se marcan como inactivos pero se conservan. Contacta a soporte para eliminar permanentemente.

**¿Hay límite de clientes que puedo crear?**
No hay límite. Puedes crear tantos clientes como necesites según tu plan.

**¿Puedo exportar la lista de clientes?**
Sí, usa la opción de exportar para obtener un archivo CSV o Excel de tus clientes.
