# Gestión de Turnos

## Introducción

Los turnos son la base para organizar las actividades de tu negocio. En esta guía aprenderás cómo crear, modificar y gestionar turnos de manera efectiva.

## Crear un Nuevo Turno

### Pasos para crear un turno:

1. Dirígete a la sección **Turnos** desde el menú principal
2. Haz clic en el botón **+ Nuevo Turno**
3. Completa los siguientes campos:
   - **Fecha**: Selecciona la fecha del turno
   - **Hora de inicio**: Hora en que comienza el turno
   - **Hora de fin**: Hora en que termina el turno
   - **Cliente**: Selecciona el cliente (opcional)
   - **Servicio**: Elige el servicio a prestar
   - **Profesional**: Asigna el profesional responsable
   - **Notas**: Agrega notas o comentarios adicionales

4. Haz clic en **Guardar**

!!! tip "Consejo"
    Puedes duplicar un turno existente para crear otro con características similares.

## Modificar un Turno

1. Busca el turno que deseas modificar
2. Haz clic en el botón **Editar** ✏️
3. Realiza los cambios necesarios
4. Haz clic en **Guardar cambios**

## Cancelar un Turno

!!! warning "Atención"
    Cancelar un turno es una acción que puede notificar al cliente. Procede con cuidado.

1. Selecciona el turno a cancelar
2. Haz clic en el botón **Más opciones** (⋮)
3. Selecciona **Cancelar turno**
4. Proporciona un motivo de cancelación
5. Confirma la acción

## Vista Calendario

La vista calendario te permite visualizar todos tus turnos en un formato de calendario mensual:

- **Haz clic** en un día para ver los turnos de ese día
- **Arrastra** un turno para cambiar su fecha
- **Doble clic** para crear un nuevo turno

## Reportes de Turnos

Accede a reportes detallados de tus turnos:

- Turnos completados
- Turnos cancelados
- Ingresos por turno
- Ocupación por profesional

!!! note "Nota"
    Los reportes se pueden descargar en formato PDF o Excel para análisis posterior.

## Preguntas Frecuentes sobre Turnos

**¿Puedo modificar un turno que ya comenzó?**
Sí, puedes modificar ciertos campos como notas, pero algunos datos como la fecha y hora podrían estar restringidos.

**¿Qué pasa si cancelo un turno?**
El cliente será notificado automáticamente si tiene configurado el envío de notificaciones.

**¿Puedo crear turnos recurrentes?**
Actualmente, puedes duplicar turnos manualmente. Consulta nuestro roadmap para futuras actualizaciones.
