    Guía de Estilo y Uso de Glymm-Docs¶

    Admoniciones (Notas, Advertencias, etc.)¶

    Usa estas etiquetas para destacar información importante:

    Nota (Azul)¶

    !!! note "Título"
    Contenido de la nota informativa

    Consejo (Verde)¶

    !!! tip "Consejo"
    Consejo útil para el usuario

    Advertencia (Amarilla)¶

    !!! warning "Atención"
    Información que requiere cuidado

    Peligro (Roja)¶

    !!! danger "Peligro"
    Acción que podría causar problemas graves

    Ejemplo (Gris)¶

    !!! example "Ejemplo"
    Ejemplo práctico de uso

    Emojis disponibles¶

    Algunos emojis útiles para la documentación:

    • 📚 :books: - Documentación
    • 🚀 :rocket: - Lanzamiento, inicio rápido
    • 💡 :bulb: - Ideas, tips
    • ⚠️ :warning: - Advertencia
    • ✅ :white_check_mark: - Correcto, completado
    • ❌ :x: - Incorrecto, error
    • 📧 :email: - Email
    • 📱 :mobile_phone: - Móvil
    • 🔒 :lock: - Seguridad
    • 📊 :bar_chart: - Gráficos, reportes
    • ⚙️ :gear: - Configuración
    • 🎯 :dart: - Objetivo

    Buenas Prácticas¶

    ✅ Hacer: - Ser claro y conciso - Usar encabezados jerárquicos - Incluir ejemplos prácticos - Proporcionar instrucciones paso a paso - Destacar advertencias importantes - Mantener actualizada la documentación

    ❌ Evitar: - Párrafos muy largos - Jerga técnica sin explicación - Información desactualizada - Estructura poco clara - Falta de ejemplos - Contenido duplicado
